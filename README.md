# Robimy Zdrowie

Statyczna strona HTML/CSS/JS. Bez npm, kompilacji i serwera.

## Cloudflare Pages
1. W Cloudflare: Workers & Pages → Create → Pages → Connect to Git.
2. Wybierz repozytorium `miko48/robimyzdrowie` i gałąź `main`.
3. Framework: None; build command: puste; build output directory: `.`.
4. Deploy. Kolejne commity do main automatycznie aktualizują stronę.

## Przed uruchomieniem
- Wykonaj testowe zgłoszenie i sprawdź odpowiedzi Google Forms oraz powiadomienia. Formularz wyświetla odpowiedź Google po wysłaniu.
- Sprawdź, czy formularz Google przyjmuje odpowiedzi bez logowania i czy usunięte pola są opcjonalne.
- Uzupełnij informację o administratorze danych, celach, podstawach, odbiorcach, przechowywaniu i prawach klientów przed udostępnieniem formularza. Nie zbieraj danych zdrowotnych bez odpowiedniego procesu ochrony danych.
- Zweryfikuj aktualne ceny i obietnicę odpowiedzi w 24h.
